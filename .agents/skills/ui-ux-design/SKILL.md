# UI/UX Design Skill for MARK-1

## Design System Guidelines
- **Framework:** React 19 + Tailwind CSS + Lucide React icons.
- **Palette:** Dark mode slate/neutral background, crisp contrast, emerald/cyan accents for success and verified badges, amber for warnings.
- **Sidepanel Dimensions:** Optimized for compact Chrome sidepanel views (320px - 450px width).
- **Accessibility:** Semantic HTML elements, ARIA labels, focus states, keyboard navigable controls.
- **Customer Nomenclature:** Always use "Customer" or "User" in labels and copy.
